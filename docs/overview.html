02 The three commands

Straight from secondbrain --help. Hover a card, then press play in the terminal below.

✍️ new

Create a new note with the given TITLE. Prints the path it wrote.

secondbrain new [OPTIONS] TITLE
TITLE (required)--help

📚 list

List all notes in the notes directory — newest first, numbered for you.

secondbrain list [OPTIONS]
no arguments--help

🔍 show

Display the contents of note NUMBER — the number you saw in list.

secondbrain show [OPTIONS] NUMBER
NUMBER (int)--help

04 Knobs you can turn

Environment variables. .env isn't auto-loaded — use uv run --env-file .env.

SECONDBRAIN_DIR default ~/secondbrain/

📂 Where your notes live. Read fresh on every call, so the environment always wins.

LOG_LEVEL default INFO

🔊 Set to DEBUG for chatty console output.

LOG_FILE default $SECONDBRAIN_DIR/app.log

📝 Rotates at 50 KB, keeps 1 backup. If it can't open, the command still runs.
